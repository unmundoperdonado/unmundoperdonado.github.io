Política de privacidad

Última actualización: 28 de octubre de 2026.

Quién usa la aplicación

La aplicación "Un mundo perdonado" es una herramienta interna del canal de YouTube del mismo nombre. Solo la usa el titular del canal, con su propia cuenta de Google. No está abierta al público.

Qué datos usa

Con el permiso que el titular concede en la pantalla de Google, la aplicación accede a la API de datos de YouTube para subir, programar, consultar y borrar los vídeos de su propio canal. No lee ni guarda datos de otras personas, ni comentarios, ni datos de visitantes.

Dónde se guardan

El permiso (token de acceso) se guarda solo en el ordenador del titular. No se envía a ningún servidor propio, no se vende y no se comparte con terceros. Los datos de YouTube se usan solo para gestionar el canal.

Cómo retirar el permiso

En cualquier momento, desde myaccount.google.com/permissions, quitando el acceso a "Un mundo perdonado".

El uso de la API de YouTube está sujeto a las Condiciones de servicio de YouTube y a la Política de privacidad de Google.
